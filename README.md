# RedPanda — сайт (редизайн)

Одностраничный статический сайт: HTML + CSS + чистый JavaScript. Сборка не нужна — всё работает из папки как есть.

Демо: https://redpanda-redesign.vercel.app

## Структура

```
redpanda-site/
├── index.html              ← русская версия (главная): разметка, стили и скрипты
├── en/index.html           ← английская версия (/en/), собирается из index.html скриптом tools/make_en.py
├── assets/
│   ├── panda-idle-v1.mp4   ← панда на первом экране (бесшовный цикл, без звука)
│   ├── panda-talk.mp4      ← панда говорит по-русски (по клику на панду), озвучка вшита
│   ├── panda-talk-en.mp4   ← панда говорит по-английски (по клику на панду на /en/), губы подогнаны под английскую озвучку
│   ├── panda-poster.jpg    ← постер первого кадра видео (показывается до загрузки)
│   ├── panda.jpg           ← фон финального блока «Ещё один шаг»
│   ├── redpanda-mark.svg   ← знак RedPanda (шапка, прелоадер)
│   ├── nonsense-labs.png   ← логотип Nonsense Labs (белый, прозрачный фон)
│   ├── ugs.png             ← логотип UGS
│   ├── intexsoft.svg       ← логотип IntexSoft
│   └── skymarketing.png    ← логотип SkyMarketing (подпись разработчика в подвале)
├── fonts/                  ← шрифты локально (Unbounded, Manrope, JetBrains Mono; кириллица + латиница)
│   └── fonts.css
├── tools/make_en.py        ← генератор английской страницы (словарь переводов внутри)
├── vercel.json             ← настройки для Vercel (кэш картинок, видео и шрифтов)
├── railway.json            ← настройки для Railway (сборка через Dockerfile)
└── railway/
    ├── Dockerfile          ← веб-сервер Caddy для Railway / любого Docker-хостинга
    └── Caddyfile
```

## Запуск локально

Нужен любой статический сервер (видео должны отдаваться по HTTP, не через file://):

```bash
cd redpanda-site
python3 -m http.server 8080
```
Открыть http://localhost:8080

или

```bash
npx serve .
```

## Деплой

**Vercel** (бесплатно, проще всего)
```bash
npm i -g vercel
vercel deploy --prod
```
Фреймворк не выбирать — это статический сайт (всё уже указано в `vercel.json`).

**Railway**
Залить папку в репозиторий GitHub → в Railway «New Project → Deploy from GitHub repo». Railway сам прочитает `railway.json` и соберёт `railway/Dockerfile`. Сервер слушает порт из переменной `PORT` (Railway задаёт её сам). После деплоя: Settings → Networking → Generate Domain.

**Из GitHub (рекомендуется для своего домена)**
- Vercel: vercel.com → Add New → Project → Import этого репозитория → Framework: Other → Deploy. Дальше каждый `git push` выкатывается автоматически.
- Свой домен: в проекте Vercel → Settings → Domains → добавить домен (например `redpanda-ai.net`) и прописать у регистратора DNS-записи, которые покажет Vercel (A `76.76.21.21` для корня или CNAME `cname.vercel-dns.com` для поддомена). HTTPS выдаётся автоматически.
- Railway: New Project → Deploy from GitHub repo → выбрать репозиторий; домен — Settings → Networking → Custom Domain.

**Любой другой хостинг** (Netlify, GitHub Pages, nginx, S3)
Просто загрузить содержимое папки как есть. Важно, чтобы сервер поддерживал Range-запросы для `.mp4` (почти все поддерживают) — это нужно Safari/iPhone для видео.

## Английская версия

Переключатель RU / EN в шапке ведёт между `/` и `/en/` внутри этого сайта.
Английская страница генерируется из русской, поэтому вёрстку и анимации правим один раз — в `index.html`:

```bash
python3 tools/make_en.py      # пересобирает en/index.html
```

Все английские тексты — в словаре внутри `tools/make_en.py` (формулировки взяты со старого английского лендинга). Если в `index.html` появилась новая русская фраза без перевода, скрипт остановится и покажет её. Ссылки на политику и условия на /en/ ведут на `privacy-en.html` и `terms-en.html`.

## Где что менять

Всё в `index.html`:
- **Цвета** — переменные в начале `<style>`: `--bg`, `--orange` (#FF4800), `--cyan` (#82E7EE) и др.
- **Тексты** — прямо в разметке. Тексты переключателя «Для себя / Для близкого» — в скрипте, объект `copy`.
- **Логотипы компаний** — блок `<section class="companies">` в конце `<main>`.
- **Подпись разработчика** — ссылка `<a class="made-by">` в подвале (логотип SkyMarketing → https://r2day.kz).
- **Ссылки** — почта, «Инвесторам», «О компании», политика и условия ведут на текущие адреса redpanda-ai.net.

## Что нужно подключить перед запуском в прод

- **Форма заявки** сейчас демонстрационная: при отправке показывает «Это макет — заявка никуда не отправлена». Подключите её к своему обработчику (тот же endpoint, что на текущем сайте): обработчик `form.addEventListener('submit', …)` в конце скрипта. Поля: `contact`, `message`, согласие `consent`.
- **Баннер cookie** визуальный — кнопки только скрывают его. Появляется, когда посетитель прокрутил первый экран (чтобы не закрывать кнопку заявки). Если нужна аналитика, подключите её в обработчиках кнопок `[data-ck]`.

## Технически

- Панда говорит по клику (тапу) на саму панду — прозрачная кнопка `#pandaHit` поверх видео; повторный клик останавливает. Отдельной кнопки звука нет.

- Без фреймворков и сборщиков. Единственная внешняя библиотека — Lenis (плавный скролл) с jsDelivr, версия зафиксирована `lenis@1.1.13`; без неё сайт работает с обычным скроллом.
- Шрифты подключены локально — сайт не делает запросов к Google.
- Анимации учитывают `prefers-reduced-motion`; видео и частицы ставятся на паузу, когда первый экран не виден.
- Видео говорящей панды подгружается только при наведении на кнопку или после загрузки страницы в фоне — первый экран лёгкий (~1 МБ).
